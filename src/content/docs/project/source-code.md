DebitMyData's code is public on GitHub, in the
[DebitMyData-PoW](https://github.com/DebitMyData-PoW) organization.

| Repository | What it is |
| --- | --- |
| [DebitMyData-PoW-Core](https://github.com/DebitMyData-PoW/DebitMyData-PoW-Core) | DebitMyData Core: the node and desktop wallet, built from Bitcoin Core |
| [electrum](https://github.com/DebitMyData-PoW/electrum) | The DebitMyData Electrum wallet |
| [electrumx](https://github.com/DebitMyData-PoW/electrumx) | The Electrum server that light wallets connect to |
| [debitmydata-yiimp](https://github.com/DebitMyData-PoW/debitmydata-yiimp) | The mining pool, pool.debitmydata.io |
| [agent-gateway](https://github.com/DebitMyData-PoW/agent-gateway) | The DebitMyData Agent Gateway: DID-LLMs, payments, the MCP server, sign-in |
| [debitmydata-monitor](https://github.com/DebitMyData-PoW/debitmydata-monitor) | Monitoring and public stats: stats.debitmydata.io |
| [debitmydata-analytics](https://github.com/DebitMyData-PoW/debitmydata-analytics) | On-chain analytics: analytics.debitmydata.io |
| [debitmydata-skill](https://github.com/DebitMyData-PoW/debitmydata-skill) | An agent skill for DebitMyData services |
| [debitmydata-docs](https://github.com/DebitMyData-PoW/debitmydata-docs) | These docs |

## Reporting a security issue

Write to [info@debitmydata.com](mailto:info@debitmydata.com) privately, not in a public issue.
The Agent Gateway's [security policy](https://api.debitmydata.io/policies/security) explains
what to send and what happens next.
